# Assignment 8 – Vehicle Classification

This project uses the `extended_data.csv` dataset to classify vehicles as premium or non-premium using Decision Tree and Random Forest models.

The notebook includes data cleaning, categorical encoding, data visualization, model training, and evaluation using accuracy, precision, recall, F1-score, ROC curves, and confusion matrices.

## Running the Notebook

Open the notebook in Google Colab, upload `extended_data.csv` to the Files panel, check that the loading path is `/content/extended_data.csv`, and run the cells from top to bottom.

The notebook uses pandas, NumPy, Matplotlib, seaborn, and scikit-learn.
