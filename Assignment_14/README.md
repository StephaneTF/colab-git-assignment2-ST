# Assignment 14 – Ethical AI Analysis and Explainability

This assignment uses the UCI Adult Census Income dataset to predict whether annual income exceeds $50,000 with logistic regression. It covers data preparation, feature scaling, model evaluation using accuracy, a confusion matrix, and a classification report. Fairlearn compares selection rates, false positive rates, and true positive rates across recorded sex groups. SHAP provides global and individual explanations, while LIME explains individual predictions. These analyses help identify model behaviour and group disparities but do not establish fairness or causation.

**Tools:** Python, pandas, scikit-learn, Matplotlib, Fairlearn, SHAP, and LIME.

**Usage:** Open the notebook in Google Colab and run the cells in order. The dataset loads automatically; install Fairlearn, SHAP, and LIME using the provided cells.

**Dataset:** UCI Adult Census Income.
